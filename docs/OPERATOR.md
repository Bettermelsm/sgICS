# sgICS 客服操作手册（给客服人员用）

> 对应系统版本 v0.8.0。工作台地址：http://localhost:8000/admin/

## 一、每天开工先看什么

打开工作台首页，顶部 4 张引导卡片：

| 卡片 | 绿色表示 |
|------|---------|
| 01 建店铺 | 店铺已建 |
| 02 配话术 | 关键词/转人工规则已配 |
| 03 接客服 | 客服工作台登录态有效 |
| 04 收草稿 | 今日已有草稿，且轮询正常 |

卡片 04 还会显示 poller 心跳：如果显示"轮询异常"，先看本文第五节排查。

## 二、审草稿并发货（核心日常工作）

1. 左侧菜单 → **回复日志**，状态为"草稿"的就是待你处理的。
2. 点每行右侧的 **「审核」** 进入审核页：
   - 上面是客户原话，下面是系统拟的回复；
   - 中间 **风控预检** 四项必须全绿（人工发送开关 / 服务时段 / 频率 / 熔断），红项会写明原因。
3. 三个动作：
   - **确认发送**（会二次确认）：文字发出；如果上传了配图，图片会紧跟着发出；
   - **转人工**：把会话转给人工客服；
   - **驳回**：这条草稿作废。
4. 每条发送/驳回都会记录**审核人**和时间，可审计。

配图：审核页有"上传配图"区，选图片上传后再点确认发送。常用图（尺码表、安装说明等）
建议先由管理员统一传好、审核时直接选用——目前版本是每条草稿单独上传。

## 三、配话术（管理员）

- **关键词规则**：客户消息命中关键词 → 按设定话术回复。右上角「话术测试」可输入一句话验证命中效果。
- **转人工规则**：命中 → 转人工。投诉、退款、大额订单等问题建议配转人工。
- 数字**优先级越大越先**匹配。

## 四、知识库（管理员）

- **知识库文档**：上传产品资料（txt/md/pdf/docx/xlsx），自动切分入库。AI 兜底时会先检索资料再回答。
- 右上角「知识库测试」：输入问题，看 AI 引用了哪几段资料。
- 资料更新后，勾选文档 → 下拉动作选「重新入库」。

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 卡片 03 显示未登录 | 跑 `python manage.py login_douyin`，手机扫码重新登录 |
| 卡片 04 显示轮询异常 | `docker compose logs poller` 看错误；连续失败会退避重试，一般自愈 |
| 审核页提示"不在服务时间窗口" | 当前不在 9:00–23:00，属正常风控 |
| 审核页提示"频率超限" | 10 分钟内已发 20 条，等一会儿再发 |
| 审核页提示"熔断" | 近 30 分钟发送失败 3 次，检查网络/登录态后重试 |

## 六、安全红线（所有人）

1. **自动回复默认关闭**：系统只生成草稿，不会自动发给客户。不要随意打开店铺的"自动回复"。
2. **人工发送开关**：每家店默认关闭，开启需管理员操作。
3. 真实发送**唯一入口**是审核页的"确认发送"，没有其他自动发送路径。
4. 数据库定期备份：`python manage.py backup_db`（备份在数据库同目录 backups/ 下）。
